# Meal Planner

A mobile-friendly web app that calculates your daily calories and macros and suggests
allergy-safe breakfast, lunch and dinner recipes.

Built with Next.js, Supabase and the Spoonacular recipe API, hosted on Vercel — all on free plans.
See [CLAUDE.md](CLAUDE.md) for the full spec and build roadmap.

## Run it on your computer

```
npm install
npm run dev
```

Then open http://localhost:3000.

Copy `.env.example` to `.env.local` and fill in the keys once Supabase and Spoonacular are set up.
